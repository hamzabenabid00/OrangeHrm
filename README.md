# OrangeHRM Automation Testing Framework

## Overview

This project is a web UI automation testing framework developed using **Java, Selenium WebDriver, Cucumber, and JUnit**, following the **Behavior-Driven Development (BDD)** approach.

The framework is designed to automate and validate functional scenarios of the OrangeHRM application using readable Gherkin scenarios and reusable automation code.

## Technologies & Tools

* **Java** – Programming language
* **Selenium WebDriver** – Web UI automation
* **Cucumber** – BDD framework for writing executable specifications
* **JUnit** – Test execution and assertions
* **Gherkin** – Business-readable test scenarios
* **Maven** – Dependency management and build automation
* **Page Object Model (POM)** – Test code organization and maintainability

## Project Objectives

* Automate web application testing.
* Apply BDD principles using Given, When, Then syntax.
* Separate test scenarios from automation implementation.
* Improve test reusability and maintainability.
* Validate application behavior through automated test execution.

## Testing Approach

This project follows the **BDD methodology**, where test scenarios are written in Gherkin syntax.

Example:

```gherkin
Feature: OrangeHRM Login

  Scenario: Login with valid credentials
    Given the user is on the OrangeHRM login page
    When the user enters valid credentials
    And clicks on the login button
    Then the user should be redirected to the dashboard
```

## Framework Architecture

The framework uses a layered structure:

* **Feature Files:** Define test scenarios using Gherkin.
* **Step Definitions:** Connect Gherkin steps to Java automation code.
* **Page Classes:** Store page elements and reusable interactions.
* **Test Runner:** Executes Cucumber scenarios through JUnit.
* **Maven:** Manages dependencies and test execution.

## Prerequisites

Make sure the following tools are installed:

* Java JDK 17 or later
* Apache Maven
* Google Chrome
* IDE (IntelliJ IDEA or Visual Studio Code)
* Git

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/hamzabenabid00/OrangeHrm.git
```

### 2. Navigate to the project directory

```bash
cd OrangeHrm
```

### 3. Install dependencies

```bash
mvn clean install
```

### 4. Execute the automated tests

```bash
mvn test
```

## Test Reports

Test execution results can be reviewed through the test reports generated by the framework and the configured Cucumber reporting mechanism.
